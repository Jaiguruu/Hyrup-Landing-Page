# HYRUP - Next-Gen Student Career Platform

HYRUP is a specialized career launchpad built by students, for students. It focuses on showcasing actual skills rather than just degrees, helping students from all backgrounds find early access to job opportunities and mentor-led communities.

## ✨ Key Features

- **Skill-Based Portraits**: Build a portfolio that highlights what you can actually do.
- **Dynamic Backgrounds**: Features a premium WebGL-based grain gradient and particle interaction system for a modern, high-end feel.
- **Smart Matching**: AI-powered discovery for job roles that match your specific skill set.
- **Mentor Communities**: Connect with industry experts and peers in your field.
- **Fully Responsive**: Optimized for every device, from mobile to desktop.
- **Dark Mode Support**: A beautiful, curated dark theme for reduced eye strain and high-contrast accessibility.

## 🛠️ Developed With

- **Framework**: React 19 (Vite)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Animations**: Framer Motion & GSAP
- **3D Particles**: OGL & React Three Fiber
- **Icons**: Lucide React

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

- [Node.js](https://nodejs.org/) (current LTS recommended)
- [NPM](https://www.npmjs.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/hyrup-clone.git
   ```

2. **Navigate to the directory**:
   ```bash
   cd hyrup-clone
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Launch the development server**:
   ```bash
   npm run dev
   ```

## 🏗️ Building for Production

To create an optimized production build:

```bash
npm run build
```

The output will be available in the `dist` folder.

## 🎨 Design Methodology

This project utilizes a **Glassmorphic** and **Neo-Minimalist** design language. It uses a combination of smooth CSS transitions and high-performance WebGL shaders to create an interactive experience that feels alive.
